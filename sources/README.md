# Selected source snapshots

Files in this directory are selected design documents, code, synthetic fixtures and historical evidence from the source corpus. They are included for inspection, not presented as a complete runnable distribution. No dependency installation or executable behavior is necessary to read the portfolio.

Original source wording may contain broader titles or historical claims. Use the case study and evidence record to understand the selected scope; do not silently treat a release title, illustrative value or old report as current authority or a fresh result. SOURCE_MANIFEST.json records original package hashes, members and source commits. No conversation logs, credentials, unrelated bulk archives or personal career documents are included.
