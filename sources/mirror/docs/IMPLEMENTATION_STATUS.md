# Implementation status

## Executable in this package

- Preserved fifteen-faculty single-process runtime and inherited API/CLI, CCP, framework ports, recommendation boundaries, checkpoints and post-action reflection.
- Frozen typed relational models with generated schemas and explicit limits.
- Source integrity, evidence families, graph reference/provenance checks and alternative-account consistency.
- Noncommutative symbolic representation, with ordered operands and reading order.
- Deterministic complete view with source closure and faithful bundle binding.
- Fixture-only revision/purpose/time/export-bound request processing.
- Candidate annotation records that have no apply operation.
- Calibration-question construction without sending or measuring.
- Explicit immutable artifact / CCP conversion.
- Reproducible regression and boundary tests.

## Specified, not implemented

- Generative hypothesis provider or reasoning model integration.
- Automatic graph generation or relational processing inside existing faculties.
- Trusted live profile-export adapters, verified consent/revocation, authenticated clocks and replay stores.
- Gaia-owned relational calibration results or empirical assessment.
- Profile mutation, authorized execution, permanent persistence, graphical editor or distributed runtime.

The executable service accepts authored graph data and returns a validated representation. It does not discover a person's cognitive architecture. Literal flags cannot detect all misleading meanings in free text; semantic review remains necessary.

Inherited deterministic examples and heuristic confidence values are preserved as reference behavior. Passing tests does not validate their developmental-science interpretation. Exact test results and environment appear in `evidence/validation_report.json`.
